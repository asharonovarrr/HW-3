# Исследование гипотезы №5 (M4 Hourly Dataset)



**Автор:** Шаронова Анастасия Андреевна

**Курс:** Анализ временных рядов

**Задание:** HW3 (Проектная работа)



## Описание проекта

Данный проект посвящен проверке гипотезы о том, что ансамбль из глобальной модели (Direct CatBoost) и локального статистического метода (AutoTheta) превосходит одиночные модели на почасовых данных.



### Основные результаты:

- **CatBoost (Direct):** продемонстрировал наилучшую точность (sMAPE ~6.4%).

- **Ансамбль:** показал средний результат, не подтвердив гипотезу о синергии из-за слабого влияния бейзлайна на почасовых интервалах.

- **Воспроизводимость:** эксперимент проведен на 100 случайных рядах с использованием кросс-валидации на расширяющемся окне.



## Структура репозитория

- `src/`: Модульная структура кода (feature engineering, модели, загрузка данных).

- `config.py`: Централизованное управление гиперпараметрами.

- `results/`: Итоговые метрики и ноутбук с визуализацией.

- `run_experiment.py`: Основной скрипт для запуска полного цикла расчетов.



## Инструкция по запуску

1. Установите зависимости: `pip install -r requirements.txt`

2. Запустите расчеты: `python run_experiment.py`

3. Результаты будут сохранены в папку `results/`.
